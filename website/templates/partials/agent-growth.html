tools:

  - name: datetime
  - name: echo

Tools

Let the agent take an action.

Make a calculator, clock, and echo tool available to the model. It can request a useful tool, read the result, and respond.

Illustrative flow

“What is 24 × 17?” → calculator → response

A tool declaration grants access; it does not force a tool call. These three tools are built in.

Add to agent.yamlMemory
memory:
  type: in-memory
  max_messages: 50

Memory

Keep the conversation in context.

Retain a bounded window of 50 messages and include that history in later turns. The model can use what was said earlier in the conversation.

Illustrative flow

“My name is Mira.” → retained history → “What is my name?”

This is conversation memory in the running process. Use storage to resume saved conversations, or actor memory to retain facts about returning people.

Add to agent.yamlStates
states:
  initial: greeting
  states:
    greeting:
      prompt: "Ask how you can help the customer."
      transitions:
        - to: technical_support
          when: "User describes a technical issue"
    technical_support:
      prompt: "Gather details and suggest troubleshooting steps."

States

Give each phase its own instructions.

Start with a greeting, then move into technical support when the transition condition matches. The active state supplies the instructions for that phase.

Illustrative flow

Greeting → “I cannot log in.” → technical support

This is a shortened adaptation of the support example. Natural-language conditions use model evaluation. The full example adds nested states, escalation, and clarification.

  initial: billing_help
  states:
    billing_help:
      delegate: billing

Multiple agents

Bring in a specialist.

Load a billing agent from its own YAML and delegate messages to it. The parent keeps the user conversation while the child handles the specialist task.

Illustrative flow

User → parent → billing specialist → response

Requires the child file agents/billing_agent.yaml relative to your agent file, with its own model configured. This excerpt delegates directly; the full recipe routes between billing and technical specialists.
