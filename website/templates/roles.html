agent.yamlCopy and adapt
name: RoleExplorer
system_prompt: "Answer clearly."
llms:
  main: { provider: openai, model: gpt-5.4-mini }
  fast: { provider: openai, model: gpt-5.4-nano }
  precise: { provider: openai, model: gpt-5.4-mini }
llm:
  default: main
  router:
    default: fast
    process:
      detect: fast
process:
  input:
    - type: detect
      config:
        llm: precise
        detect: [language]
tools: []

Running this YAML uses your configured OpenAI credentials. The explorer itself does not run it.

One selection rule, existing execution contracts.

A role setting chooses a model for an enabled feature. It does not enable tools, approve a request, or turn a missing alias into a fallback. An omitted or scalar router keeps legacy selection; an empty mapping opts into hierarchical inheritance.
